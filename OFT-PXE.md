# How to enable PXE boot function on BIOS

Please follow up the steps below to enable it.  

1. Please press `F2` when system booting up.  
2. Please select `Boot` table and `Network Stack` as below then enable it.  
   ![PXE_on_1](images/OFT-PXE/PXE_on_1.png)  
3. Please select `PXE Boot capability` and `UEFI:IPv4/IPv6` to enable it.  
   ![PXE_on_2](images/OFT-PXE/PXE_on_2.png)  
4. Press `F10` for saving the settings, system will restart.  
5. Please press `10` when system booting up and you will see boot device with network.  
   ![PXE_on_3](images/OFT-PXE/PXE_on_3.png)
